# VoiceOver Studio

Программа для Windows для **многоголосой озвучки** фильмов, сериалов, мультфильмов и аниме.
Голоса можно делать нейросетью, записывать живыми актёрами или совмещать оба способа в одном проекте.

## Возможности

- **Импорт субтитров** SRT / ASS / SSA / VTT. Персонажи определяются автоматически:
  - ASS — по полю *Actor/Name* (или по стилю, если имён нет);
  - VTT — по тегу `<v Имя>`;
  - SRT — по префиксу `Имя: текст` или `[Имя] текст`.
- **Распознавание речи Whisper.** Если субтитров нет, программа сама расшифрует речь
  (японский, английский, русский и другие языки) и создаст реплики с таймингами.
  Длинные фразы режутся по предложениям и паузам, мусор вроде «Субтитры сделал…» отсеивается.
  Если голоса уже отделены, распознавание идёт по чистым голосам и получается точнее.
  Работает на процессоре и на видеокартах NVIDIA, PyTorch для этого не нужен.
- **Персонажи и голоса.** У каждой роли свой цвет и свой голос.
  - **AI-синтез:** Edge TTS (бесплатно, нужен интернет) или Silero (офлайн).
    Голосу задаются темп и высота, поэтому один голос может звучать по-разному.
  - Кнопка «Раздать голоса» автоматически назначает персонажам разные голоса.
  - **Живая запись:** суфлёр с текстом реплики, преролл видео, отсчёт «ГОВОРИТЕ»,
    автостоп и переход к следующей реплике той же роли, индикатор уровня микрофона.
    Тишина по краям дубля обрезается сама, синхрон при этом сохраняется.
- **Два типа сведения:**
  - **Закадровая озвучка:** оригинал плавно приглушается под репликами (уровень, атака и восстановление настраиваются);
  - **Дубляж:** оригинальные голоса удаляются нейросетью Demucs, а музыка и звуки остаются.
- **Подгонка под тайминг.** Длинные реплики ускоряются без изменения тона (до заданного предела),
  громкость реплик выравнивается, мягкий лимитер не даёт звуку перегружаться.
- **Таймлайн** с дорожками персонажей. Реплики можно перетаскивать и растягивать мышью, клик по шкале перематывает видео.
- **Превью:** собранная озвучка играет синхронно с видео прямо в программе (F6).
- **Экспорт** в MKV/MP4: видео копируется без перекодирования, новая дорожка ставится
  первой и по умолчанию, оригинал идёт второй, субтитры сохраняются. Кодеки: AAC / AC3 / Opus / FLAC.
  Можно экспортировать только звуковую дорожку или сценарий (SRT с ролями).
- **Перевод реплик** (Ctrl+Shift+T) с сохранением оригинала. Переводчики на выбор:
  - **локально, без интернета** — модель NLLB-200 (Meta) через CTranslate2: 200 языков, в том
    числе японский→русский напрямую, без лимитов; модель (600 МБ или 1.4 ГБ) скачивается один раз
    в `%APPDATA%\VoiceOverStudio\models`; лицензия модели — некоммерческое использование;
  - **DeepL** — лучшее качество, нужен бесплатный ключ API (500 000 символов в месяц);
  - **Google Переводчик** — без ключа, но может временно блокировать частые запросы.
- **Субтитры с видео** (Ctrl+Shift+O) — распознавание вшитых в кадр субтитров (OCR).
- **Отмена и повтор** (Ctrl+Z / Ctrl+Y) любых правок: текста, таймингов, ролей, голосов,
  удаления реплик, импорта и распознавания. Быстрый набор текста отменяется одним шагом.
- **Тёмная и светлая темы** (Ctrl+T), стартовый экран с недавними проектами, волна звука
  оригинала на таймлайне, строка «кто сейчас говорит» под видео.
- Проекты хранятся в файлах `.vop`. Есть автосохранение и кэш синтеза: заново озвучиваются только изменённые реплики.

## Установка (Windows 10/11)

1. Установите **Python 3.12** (подходят 3.10–3.13) с [python.org](https://www.python.org/downloads/)
   и при установке отметьте *Add python.exe to PATH*. Для Python 3.14 и новее часть библиотек
   (onnxruntime для Whisper, PyTorch) ещё не собрана. Новую версию удалять не нужно:
   `setup.bat` сам выберет подходящую через `py`.
2. Скачайте проект (Code → Download ZIP) и распакуйте его.
3. Запустите **`setup.bat`**. Он:
   - найдёт подходящий Python и создаст окружение `.venv` (если `.venv` был создан другой
     версией Python, пересоздаст его);
   - установит основные модули (около 300 МБ);
   - отдельным шагом установит Whisper — если не получится, программа будет работать
     без распознавания речи;
   - спросит, ставить ли AI-модули (Silero и Demucs, 2–4 ГБ) и есть ли видеокарта NVIDIA
     (с ней удаление голосов работает в 10–30 раз быстрее).
4. Запускайте программу через **`run.bat`**.

FFmpeg ставится автоматически (пакет `imageio-ffmpeg`). Если хотите свою версию FFmpeg,
положите её в папку `ffmpeg\bin\` рядом с программой или укажите путь в
*Файл → Настройки*.

### Сборка .exe

`build.bat` собирает лёгкую версию без PyTorch в `dist\VoiceOverStudio\`.
`build.bat full` собирает полную версию с Demucs и Silero, если они установлены.
Лёгкая сборка также делается автоматически в GitHub Actions (`.github/workflows/build-windows.yml`).

## Как пользоваться

1. **Файл → Новый проект.** Выберите видео, аудиодорожку оригинала и, если есть, файл субтитров.
   Если субтитры лежат рядом с видео и называются так же, они подставятся сами. Затем выберите тип: закадровая озвучка или дубляж.
2. **Текст реплик.**
   - *Субтитры:* в окне предпросмотра видно, какие персонажи найдены.
     Если субтитры от другого релиза, задайте сдвиг времени.
   - *Распознать (Ctrl+R):* выберите язык и модель. Рекомендуется `large-v3-turbo`, а для слабых ПК — `small`.
     Попробуйте сначала «5 минут от курсора». Распознанные реплики приходят без ролей:
     выделите реплики одного персонажа и выберите его в списке «Роль».
     Модель скачивается один раз и сохраняется в `%APPDATA%\VoiceOverStudio\models`.
3. **Вкладка «Персонажи».** Для каждой роли выберите «Синтез речи (AI)» или «Живая запись».
   Кнопка «▶ Прослушать голос» даёт послушать, как звучит выбранный голос.
4. **Вкладка «Реплики».** Здесь правятся текст, время и роль. Чтобы назначить роль сразу нескольким репликам,
   выделите их и выберите персонажа в списке «Роль».
   Статусы реплик: ✔ синтез, ● запись, — нет звука, ↻ устарела (текст или голос изменились после синтеза).
5. **F5** синтезирует все AI-реплики.
6. **Вкладка «Запись»** нужна для живых ролей. Выберите реплику и нажмите **R**: видео пойдёт с преролла,
   а когда появится «ГОВОРИТЕ», читайте текст. Запись остановится сама. Пишите в наушниках, иначе
   включите «Без звука видео при записи». Если дубль немного не попал в синхрон, поправьте поле «Сдвиг».
7. **Дубляж:** запустите *Обработка → Отделить голоса*.
8. **F6** собирает превью на минуту от курсора и сразу его проигрывает. Звук плеера переключается
   в выпадающем списке под видео.
9. **Ctrl+E** открывает экспорт.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+R | Распознать речь (Whisper) |
| Ctrl+T | Сменить тему |
| Пробел | Пуск / пауза (во время записи — стоп) |
| ← / → | Перемотка на 2 с |
| P | Прослушать звук выделенной реплики |
| N | Новая реплика в позиции курсора |
| R | Запись (на вкладке «Запись») |
| Del | Удалить выделенные реплики |
| F5 / Ctrl+Enter | Синтезировать все / выделенные реплики |
| F6 / Shift+F6 | Превью минуты от курсора / всего фильма |
| Ctrl+колесо, Ctrl +/− | Масштаб таймлайна |
| Двойной клик по блоку | Проиграть реплику с видео |

## Структура проекта на диске

```
Фильм.mkv
Фильм.vop              ← проект (JSON)
Фильм_files/
  original.wav         ← звук оригинала
  background.wav       ← фон без голосов (после Demucs)
  tts/                 ← синтезированные реплики (кэш)
  vocals.wav           ← голоса оригинала (после Demucs, для Whisper)
  rec/                 ← записи актёров (все дубли; лишние удаляет «Правка → Удалить неиспользуемые файлы»)
  cache/               ← подготовленные к сведению клипы
```

## Для разработчиков

```
pip install -r requirements-dev.txt
pytest -q
python run.py
```

Код:

- `voiceover/core/` — логика без интерфейса: модель проекта, история отмены, субтитры, FFmpeg,
  сведение, Demucs, Whisper, запись, пакетный синтез, волна;
- `voiceover/tts/` — движки синтеза речи;
- `voiceover/ui/` — интерфейс на PySide6 (`theme.py` — темы, стили и векторные иконки).

Новый TTS-движок добавляется так: унаследуйте класс от `TTSEngine` и зарегистрируйте его в `tts/base.py`.
