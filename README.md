# VoiceOver Studio

Программа для Windows для **многоголосой озвучки** фильмов, сериалов, мультфильмов и аниме
живыми актёрами: текст реплик, роли, запись под видео, сведение и экспорт готовой дорожки.

## Возможности

- **Импорт субтитров** SRT / ASS / SSA / VTT. Персонажи определяются автоматически:
  - ASS — по полю *Actor/Name* (или по стилю, если имён нет);
  - VTT — по тегу `<v Имя>`;
  - SRT — по префиксу `Имя: текст` или `[Имя] текст`.
- **Распознавание речи Whisper.** Если субтитров нет, программа расшифрует речь (японский,
  английский, русский и другие языки) и создаст реплики с таймингами. Если голоса уже отделены,
  распознавание идёт по чистым голосам и получается точнее. Работает на процессоре; на
  видеокарте NVIDIA — быстрее, если установлены библиотеки CUDA (если их нет, программа
  сама переходит на процессор).
- **Роли по голосам** (*Обработка → Роли по голосам*): реплики раскладываются по персонажам по
  звучанию голоса (модель WeSpeaker, ~25 МБ, скачивается один раз; без интернета — упрощённый
  способ). Отметьте по 2–3 реплики каждого персонажа — остальные программа определит сама.
- **Перевод реплик** (Ctrl+Shift+T) с сохранением оригинала. Переводчики на выбор:
  - **локально, без интернета** — модель NLLB-200 (Meta): 200 языков, без лимитов; модель
    (600 МБ или 1.4 ГБ) скачивается один раз; лицензия модели — некоммерческое использование;
  - **DeepL** — лучшее качество, нужен бесплатный ключ API;
  - **Google Переводчик** — без ключа, но может временно блокировать частые запросы.
- **Орфография и ударения** в тексте реплики: ошибки подчёркиваются (словари LibreOffice —
  русский, английский, украинский; скачиваются один раз), правый клик — варианты и «Добавить в
  словарь». Ударение — Ctrl+' после гласной. Пометки для актёра в скобках суфлёр показывает
  курсивом.
- **Персонажи и актёры.** У каждой роли свой цвет, актёр, громкость и обработка голоса:
  эффект (рация, телефон, мегафон, за стеной, комната, зал, пещера, мысли, голос ниже/выше),
  компрессор и «тембр как в оригинале» (окраска записи подгоняется под звук сцены).
  **Библиотека составов** («Сохранить состав…» / «Загрузить состав…») переносит актёров и
  настройки между сериями; новые персонажи из импорта сразу получают их из состава.
- **Ритмо-лента** под видео (Ctrl+B): текст реплик бежит через линию синхрона, каждое
  слово растянуто на время звучания (по таймингу Whisper или по слогам). Пометки в скобках —
  «(смеётся)», «[шёпотом]» — на ленту не попадают.
- **Запись живых актёров:** суфлёр с текстом реплики и соседних, преролл видео, отсчёт
  «Говорите», автостоп и переход к следующей реплике той же роли, индикатор уровня микрофона.
  Тишина по краям дубля обрезается сама, синхрон при этом сохраняется; сдвиг можно подправить.
  Все дубли сохраняются: в списке «Дубль» можно переключаться между ними и выбрать лучший.
  Кнопка **«Слышать себя»** включает свой голос в наушниках с эффектом роли (рация, телефон,
  эхо…), пока она нажата.
  Режим «По кругу» пишет дубль за дублем, пока не нажмёте «Стоп». У дубля можно поправить
  громкость, обрезать начало и конец и сделать плавные края — волна записи видна на таймлайне.
  Обрезать можно и мышью: под полями — волна дубля поверх бледной волны оригинала и границ
  реплики; края тянут обрезку, квадратики — нарастание и затухание, сама волна — сдвиг.
  **Автоподгонка к оригиналу**: запись сдвигается так, чтобы её слоги и паузы совпали с голосом
  оригинала (кнопка «Подогнать», сразу после записи или *Обработка → Подогнать записи*, Ctrl+L).
- **Актёры на удалёнке** (*Файл → Актёры на удалёнке*): режиссёр сохраняет «пакет для актёра» —
  проект и сценарий его ролей (без видео, у актёра своя копия серии). Актёр открывает пакет в
  этой же программе, записывает и нажимает «Отправить записи». Режиссёр загружает полученный
  zip — записи встают в свои реплики новыми дублями, даже если тайминг с тех пор поправили.
- **Шумоподавление записей** (вкладка «Сведение»): шум компьютера и улицы, гул, удары по
  столу убираются при сведении, исходные записи не меняются.
- **Два типа сведения:**
  - **закадровая озвучка:** оригинал плавно приглушается под репликами;
  - **дубляж:** оригинальные голоса удаляются нейросетью Demucs, музыка и звуки остаются.
    Голоса убираются только под репликами, а между ними звучит оригинал: нейросеть иногда
    принимает за голос крики, шум толпы или тихий фон (отключается галочкой
    «Убирать голоса только под репликами»).
- **Окно актёра** (кнопка «Окно актёра», Ctrl+Shift+A): видео с отсчётом, крупным суфлёром
  и ритмо-лентой отдельным окном — само открывается во весь экран на втором мониторе (F11 —
  переключить). Во время записи поверх видео — отсчёт 3-2-1, «Говорите» и красная рамка REC.
- **Метки режиссёра** на таймлайне: двойной клик по линейке или M — заметка к моменту фильма,
  щелчок по флажку — изменить или удалить, Alt+←/→ — переход между метками.
- **Таймлайн** с дорожками персонажей и волной оригинала (после отделения — две дорожки:
  голоса и фон, каждую можно заглушить кнопкой у дорожки или на вкладке «Сведение»).
  Реплики перетаскиваются и растягиваются мышью; если тянуть курсор или реплику к краю,
  таймлайн прокручивается сам. **Превью** собранной озвучки играет синхронно с видео (F6).
- **Оформление релиза** при экспорте: логотип команды в углу, вшитые субтитры и заставка
  перед фильмом (видео при этом перекодируется).
- **Экспорт** в MKV/MP4: видео без перекодирования, новая дорожка первой и по умолчанию,
  за ней все звуковые дорожки исходника (языки, комментарии) с их названиями, субтитры
  сохраняются.
- **Несколько звуковых дорожек**: в плеере можно слушать любую дорожку файла; основную
  (для волны, распознавания и отделения голосов) можно сменить: *Обработка → Основная
  дорожка оригинала*. **Громкость по стандарту**: EBU R128 (−23 LUFS),
  −16 или −14 LUFS. **Экспорт субтитров** (Ctrl+Shift+E): SRT или ASS — перевод, оригинал
  или оба, с именами и цветами персонажей.
- **Сценарий для актёров** (*Файл → Сценарий для актёров*): PDF или HTML — сводка по ролям
  (реплик, слов, записано) и реплики каждой роли с таймкодами и заметками.
- **Проверка режиссёром**: дубль можно «Одобрить» (A) или отправить «На переписку» (X) с
  комментарием — он виден актёру над текстом реплики и в сценарии. Статусы «одобрено» и
  «переписать» в таблице, фильтрах, счётчиках и на таймлайне; новая запись снимает отметку.
- **Соло и заглушение ролей**: кнопки S и M у дорожек персонажей на таймлайне.
- **Экспорт по дорожкам** (*Файл → Экспорт по дорожкам*): фон, голоса каждого персонажа и
  микс отдельными WAV и проект Reaper, где каждая реплика — отдельный клип.
- **Пакетная обработка серий** (*Обработка → Пакетная обработка*): извлечь звук, отделить
  голоса и экспортировать несколько серий подряд, с отчётом по каждой.
- **Отмена и повтор** (Ctrl+Z / Ctrl+Y) любых правок; автосохранение; тёмная и светлая темы.
- **Резервные копии проекта**: при сохранении предыдущая версия копируется в папку `backups`
  (последние 30); *Правка → Восстановить из резервной копии*.

## Установка (Windows 10/11)

1. Установите **Python 3.12** (подходят 3.10–3.13) с [python.org](https://www.python.org/downloads/)
   и при установке отметьте *Add python.exe to PATH*. Для Python 3.14 и новее часть библиотек
   ещё не собрана. Новую версию удалять не нужно: `setup.bat` сам выберет подходящую через `py`.
2. Скачайте проект (Code → Download ZIP) и распакуйте его.
3. Запустите **`setup.bat`**. Он:
   - найдёт подходящий Python и создаст окружение `.venv` (если `.venv` был создан другой
     версией Python, пересоздаст его);
   - установит основные модули;
   - отдельным шагом установит Whisper и локальный перевод — если не получится, программа
     будет работать без них;
   - спросит, ставить ли удаление голосов Demucs (2–4 ГБ, нужно для дубляжа) и есть ли
     видеокарта NVIDIA (с ней удаление голосов работает в 10–30 раз быстрее).
4. Запускайте программу через **`run.bat`**.

FFmpeg ставится автоматически (пакет `imageio-ffmpeg`). Свою версию FFmpeg можно положить в
папку `ffmpeg\bin\` рядом с программой или указать путь в *Файл → Настройки*.

Журнал ошибок: `%APPDATA%\VoiceOverStudio\voiceover.log`; журнал отделения голосов —
`Фильм_files\separation.log`.

### Сборка .exe

`build.bat` собирает версию без PyTorch в `dist\VoiceOverStudio\`; `build.bat full` — с Demucs,
если он установлен.

## Как пользоваться

1. **Файл → Новый проект.** Выберите видео, аудиодорожку оригинала и, если есть, субтитры.
   Выберите тип: закадровая озвучка или дубляж.
2. **Текст реплик:** импорт субтитров или «Распознать» (Whisper), при необходимости —
   «Перевести». После распознавания назначьте роли: выделите реплики одного персонажа и
   выберите его в списке «Роль».
3. **Вкладка «Персонажи».** Укажите актёра для каждой роли. Чтобы в следующей серии не
   настраивать заново — «Сохранить состав…».
4. **Вкладка «Запись».** Выберите реплику и нажмите **R**: видео пойдёт с преролла, а когда
   появится «Говорите», читайте текст. Запись остановится сама. Пишите в наушниках, иначе
   включите «Без звука видео при записи».
5. **Дубляж:** *Обработка → Отделить голоса*.
6. **F6** — превью минуты от курсора вместе с видео. **Ctrl+E** — экспорт.

### Горячие клавиши

Любое сочетание можно поменять: *Вид → Горячие клавиши* (педаль или кнопку на микрофоне
назначают так же — нажатием).

| Клавиша | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+R | Распознать речь (Whisper) |
| Ctrl+L | Подогнать записи выделенных реплик к оригиналу |
| Ctrl+' | Ударение на гласной перед курсором (в тексте реплики) |
| Ctrl+Shift+T | Перевести реплики |
| Ctrl+T | Сменить тему |
| Ctrl+B | Показать / скрыть ритмо-ленту |
| Пробел | Пуск / пауза (во время записи — стоп) |
| ← / → | Перемотка на 2 с |
| R | Запись / стоп (на вкладке «Запись») |
| P | Прослушать запись выделенной реплики |
| N | Новая реплика в позиции курсора |
| Ctrl+K / Ctrl+J | Разрезать реплику по курсору / склеить выделенные |
| M / Alt+← / Alt+→ | Поставить метку / к предыдущей / к следующей метке |
| [ / ] | Предыдущая / следующая реплика роли |
| Del | Удалить выделенные реплики |
| F6 / Shift+F6 | Превью минуты от курсора / всего фильма |
| Ctrl+E / Ctrl+Shift+E | Экспорт видео / субтитров |
| Ctrl+колесо, Ctrl +/− | Масштаб таймлайна |
| Двойной клик по блоку | Проиграть реплику с видео |

## Структура проекта на диске

```
Фильм.mkv
Фильм.vop              ← проект (JSON)
Фильм_files/
  original.wav         ← звук оригинала
  background.wav       ← фон без голосов (после Demucs)
  vocals.wav           ← голоса оригинала (после Demucs, для Whisper)
  backups/             ← резервные копии проекта
  rec/                 ← записи актёров (все дубли; лишние удаляет «Правка → Удалить неиспользуемые файлы»)
  cache/               ← подготовленные к сведению клипы
  separation.log       ← журнал последнего отделения голосов
```

## Для разработчиков

```
pip install -r requirements-dev.txt
pytest -q
python run.py
```

- `voiceover/core/` — логика без интерфейса: модель проекта, история отмены, субтитры, FFmpeg,
  сведение, Demucs, Whisper, перевод, составы, запись, волна;
- `voiceover/ui/` — интерфейс на PySide6 (`theme.py` — темы, стили и иконки).
