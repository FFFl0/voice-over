# Лицензионное соглашение — черновик

Шаблон для *Steamworks → Приложение → Юридическое → EULA*. Это не юридическая консультация:
перед публикацией покажите текст юристу, особенно разделы 11–12 (ответственность, право и споры).

Заполните поля в квадратных скобках:

- `[ИЗДАТЕЛЬ]` / `[PUBLISHER]` — ваше имя или название компании, как в Steamworks;
- `[EMAIL]` — адрес для связи;
- `[СТРАНА]` / `[COUNTRY]` — страна, по законам которой действует соглашение;
- `[ДАТА]` / `[DATE]` — дата редакции.

В Steam вставляются обе версии: русская для русского языка магазина, английская для остальных.
